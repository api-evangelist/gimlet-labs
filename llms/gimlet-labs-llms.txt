# Gimlet Labs

> Gimlet Labs is an applied research lab building high-performance AI infrastructure — inference systems, schedulers, and compilers optimized for agentic and multimodal AI workloads across heterogeneous hardware. As of mid-2026 the developer surface is largely pre-launch (waitlist / gated docs); no public OpenAPI, SDKs, or MCP server were found. This file is generated from the API Evangelist catalog entry, not a provider-published llms.txt.

## Products

- [Gimlet Cloud](https://gimlet.ai): Agent-native, serverless managed inference cloud for deploying single- and multi-agent workloads that combine LLMs, multimodal, diffusion models, code sandboxes, web search, and custom data sources, with automatic scaling and heterogeneous hardware optimization.
- [kforge](https://kforge.ai): Autonomous kernel generation for PyTorch — generates optimized low-level kernels directly from PyTorch across CUDA, ROCm, and Metal (NVIDIA, AMD, Intel, Apple) without manual kernel writing.
